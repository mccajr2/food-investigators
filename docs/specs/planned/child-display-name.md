## Problem

The product talks about “he” / the child but never stores a name. Parents should
optionally set a child’s first name at signup (and edit later) so Plan / Run /
celebration copy can feel personal — still **one** child per household.

## Non-goals (sketch)

- Multiple kids (`multi-child-profiles` — parked)
- Legal name / school ID / PII beyond a display first name
- Avatar / photo profiles

## Notes

- Softens “multi-child early” by landing identity without multi-profile complexity.
- Keep optional; default copy if blank.
